TERRALAND — LINUX x64 SERVER HOSTING

This ZIP contains application source and a Dockerfile. It is not a prebuilt
Linux binary. Build it on the Linux x64 server so SQLite's native module
matches the host.

REQUIREMENTS

- Linux x64 server
- Docker Engine and Docker CLI
- A domain name and TLS reverse proxy (recommended for public hosting)

DEPLOY

1. Copy and extract terraland-linux-x64-source.zip on the server.
2. Change into the extracted project folder.
3. Create a private .env file from the example:

      cp .env.example .env

   Edit .env and set:
   - ADMIN_PASSWORD to a long, unique password
   - NEXT_PUBLIC_SITE_URL to your public HTTPS site URL
   - RESEND_API_KEY and EMAIL_FROM if you want registration notifications

   Do not commit or publicly expose .env.

4. Build the app image on this server:

      docker build --build-arg NEXT_PUBLIC_SITE_URL=https://your-domain.example -t terraland:latest .

   Replace the example with the same public HTTPS URL configured in .env.

5. Start the app with persistent storage for the database and all uploaded listing media:

      docker run -d --name terraland --restart unless-stopped \
        -p 3000:3000 --env-file .env \
        -v terraland-data:/app/data \
        terraland:latest

6. Configure your TLS reverse proxy to forward HTTPS traffic to port 3000.
   Keep port 3000 private to the server or trusted proxy. Allow request bodies
   up to 1 GB and a 300-second upload timeout for /api/admin/backup; for nginx,
   set client_max_body_size 1g in the site configuration.

BACKUPS AND UPDATES

- The terraland-data volume contains both the SQLite database and listing media.
  Back up this volume regularly. The admin dashboard also provides a portable
  Download backup / Upload backup file containing both.
- This SQLite/local-photo deployment supports one app instance only.
- For an update, build a new image from the new source and restart the
  container while retaining the named volume.
- For multiple app instances, migrate to managed database and image storage.
